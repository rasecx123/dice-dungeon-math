# Dice Dungeon Math

![Gameplay Screenshot](screenshot.png)

A fantasy-themed educational math game prototype built with Phaser 4.

## Gameplay

- Solve multiplication problems.
- Roll a D20 after each correct answer.
- Deal damage equal to:

Damage = Correct Answer + Dice Roll

- Rolling a natural 20 triggers a critical hit.
- Defeat the Math Dragon before your HP reaches zero.

## Features

- Phaser 4
- Health bars
- Boss battle gameplay
- Critical hit system
- Victory and defeat states
- Restart functionality
- AI-generated art assets

## Installation

